# QCDF

Dies ist eine Desktop-Anwendung für kooperative Funkpeilung.

## Abhängigkeiten

- Qt 6.9.3
- [Eigen 3.4.1](https://libeigen.gitlab.io/) (bereits im Repo enthalten)
- [qt_zoomable_chart_widget](https://github.com/martonmiklos/qt_zoomable_chart_widget) (bereits im Repo enthalten)
